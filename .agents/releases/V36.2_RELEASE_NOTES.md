## 🔬 1. Executive Summary

Version 36.2 introduces a systemic language governance upgrade across the **Marcus Fleet Enterprise Operating System (`.agents`)**. While previous versions established the Planning-First gate and Design System token compliance, documentation generation occasionally drifted into English due to English-only template comments and an ASCII-only word count regex in substance validation.

Version 36.2 resolves this completely by establishing the **Vietnamese-First Documentation Mandate**, upgrading substance validation regex to full Unicode word counting, embedding bilingual/Vietnamese instructions across all scaffolding templates, and adding explicit language governance into core documentation skills.

---

## 🏗️ 2. Key Architectural Upgrades

### 2.1. Absolute Directive 4: Vietnamese-First Documentation Mandate
- **100% Professional Vietnamese**: Added Absolute Directive 4 into root `.clinerules`, `.agents/.clinerules`, and `agents.md`. All generated documentation (`spec.md`, `plan.md`, `tasks.md`, `verification.md`, `prd.md`, `docs/development/E-###-*/`, `issues.md`, `screen-catalog.md`, `state-coverage.md`, `review.md`, User Stories, Acceptance Criteria, Work Log) must be authored in clear, professional Vietnamese.
- **Preserve Code Identifiers**: Variable names, function names, classes, file paths, endpoints, tokens, and international technical terms remain in standard code backticks.

### 2.2. Unicode Word Count Upgrade in `validate_docs_substance.py`
- Upgraded `markdown_word_count` from ASCII `[A-Za-z0-9]` to full Unicode regex `\b[\w/-]+\b`.
- Vietnamese sentences with diacritics (`được`, `quản lý`, `triển khai`, `đơn hàng`) are now counted accurately without being penalized or rejected by substance validators.

### 2.3. Scaffolding Templates Vietnamese Directives
- Added explicit language directives (`<!-- QUY TẮC NGÔN NGỮ: Viết 100% nội dung tài liệu này bằng Tiếng Việt chuẩn mực, rõ ràng. -->`) across `spec-template.md`, `plan-template.md`, `tasks-template.md`, `verification-template.md`, `development-epic-template.md`, `development-feature-template.md`, `development-task-template.md`, `development-issues-template.md`.

### 2.4. Documentation Skills Language Governance
- Hardened `sophia-product-manager`, `noah-agile-product-owner`, `development-ledger-architect`, `alan-tech-lead` with operating rules requiring 100% Vietnamese output for requirements, user stories, work logs, and development ledgers.
