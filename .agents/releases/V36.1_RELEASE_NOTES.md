## 🔬 1. Executive Summary

Version 36.1 delivers a critical governance and cognitive alignment upgrade to the **Marcus Fleet Enterprise Operating System (`.agents`)**. It directly addresses and neutralizes two fundamental failure modes in autonomous coding agents:

1. **Pre-Mature Code Generation (Action Bias)**: Agents jumping directly to source code edits before completing and validating the Planning Phase.
2. **Design System Token Hallucination**: Agents inventing arbitrary hex colors, typography, or component styles instead of grounding strictly in the user's project design system.

---

## 🏗️ 2. Key Architectural Upgrades

### 2.1. Absolute Directive 1: Planning-First Mandate
- **No Code Before `/develop`**: The top-level constitution in `.clinerules` and `agents.md` now establishes Planning as the absolute default.
- **Strict Tool Refusal**: Calling file mutation tools (`write`, `edit`, `replace`) is strictly blocked unless the user explicitly invokes `/develop` or `/quick_fix` and an approved planning package exists.
- **Natural Language Prompts**: Any open-ended prompt without `/develop` triggers Discovery (`/marcus.specify` / `/planning`), builds Flow and 8-State Coverage Matrices, and **halts for operator approval**.

### 2.2. Absolute Directive 2: 100% Local Design System Fidelity (Zero-Fabrication)
- **Purged Hardcoded Styles**: Removed legacy global hardcoding (*Glassmorphism/Zinc-950*) from `.clinerules`.
- **Local Token Grounding**: Mandates that before writing any UI code, the agent must inspect the user project's local design tokens (`tailwind.config.*`, CSS Variables in `globals.css`/`tokens.css`, `tokens.json`, or `.agents/design-systems/<domain>/DESIGN.md`).
- **Zero-Fabrication Rule**: Prohibits inventing arbitrary hex color codes, spacing, or component variants not declared in the project's design system.

### 2.3. Full 76/76 Skill Contract Standardization
- **100% Passing `validate_skill_contracts.py`**: All 76 skills in `.agents/skills/` (including all 11 V35/V36 design skills) now contain:
  - `references/*.md` contract documents.
  - Mandatory sections (`## Required Reads`, `## Operating Rules`, `## Output Expectations`, `## Superpowers V34 Discipline`).
  - Strict line-count limits ($\le 40$ lines) for optimal context budget.
  - Complete discoverability in `SKILLS_INDEX.md`.

### 2.4. Zero-Fabrication TrustGraph Offline Fallback
- Sanitized `trustgraph_query.py` offline fallback: Eliminated simulated/fake module dependencies and historical bugs when Neo4j is offline, emitting clean status signals instead of hallucinated context.

## 📖 4. User Playbook & Upgrade Guide

1. **Planning a Feature**:
   - Provide your prompt naturally (e.g. *"Design crypto wallet balance screen"*).
   - The AI will automatically route to `/marcus.specify` or `/planning`, inspect your local tokens, generate `spec.md`, `plan.md`, `tasks.md`, and **halt for your review**.
2. **Executing Code**:
   - Once approved, invoke `/develop`.
   - The AI will bind 100% to your project's design system and execute with modular screen subagents.
